Every screen in the Figma file's 02 · Prototype page, mapped into one journey. Numbers in brackets are Figma node ids (6:xx). Dashed red boxes are steps with no screen yet.

The core loop (write, rehearse, record, review, download) is well covered, including states most designs skip: edit conflicts, lost reading position, legacy script recovery, denied camera access and download handoff. The cycle is open at both ends. An invitation can't become an account, a password reset can't be finished, and the headline promise, controlling the prompter from your phone, has no app screens.

5 · Before building

Decisions

Decided 19 NovPhone remote (G3) and Tilw Plus (G6) are deferred. Phase 1 is a static build with no backend: data lives in the browser through the mock layer. Invite, set new password, account edit and delete account (G1, G2, G4, G5) are built from the existing sign-in and settings frames, scheduled in tasks.md. Reading settings are account-wide; text direction is per script (G15).

All phase 1 decisions are made. The public contact address is a placeholder until you have the real one (G16). Implementation starts with Setup and Foundation in tasks.md.
